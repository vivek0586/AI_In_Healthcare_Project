# Breast tumor classification with logistic regression

AI in Healthcare course self-learning tutorial project.

[![Open notebook in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/vivek0586/AI_In_Healthcare_Project/blob/main/notebooks/breast_cancer_tutorial.ipynb)

An end-to-end, self-guided healthcare machine-learning tutorial for students. It uses the public Wisconsin Diagnostic Breast Cancer dataset distributed with scikit-learn, builds a leakage-safe preprocessing/model pipeline, and evaluates malignant-versus-benign classification on a held-out test set.

> **Educational use only.** This is a small, historical benchmark dataset. The model is not a screening, diagnostic, or treatment tool and must not be used for patient care.

## Learning goals

After completing the tutorial, learners should be able to:

1. describe the prediction target, unit of analysis, and feature table;
2. preserve the meaning of the positive class when encoding labels;
3. create a stratified train/test split before fitting transformations;
4. scale features inside a scikit-learn `Pipeline` to prevent leakage;
5. interpret a confusion matrix, sensitivity, specificity, and ROC AUC;
6. explain why benchmark performance does not establish clinical readiness.

## Teaching deck

The [18-slide presentation](presentation/breast_cancer_ml_tutorial.pptx) includes speaker notes, a short feature explanation, code walkthroughs for target encoding and the leakage-safe pipeline, an editable confusion matrix and ROC curve, a coefficient chart, and a threshold exercise with discussion prompts.

## Dataset

The dataset contains 569 samples and 30 numeric measurements derived from digitized images of fine-needle aspirate samples. The classes are 212 malignant and 357 benign. Scikit-learn includes a copy, so the tutorial does not download patient-level files at run time. Read the dataset documentation and limitations before teaching it:

- [scikit-learn dataset documentation](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_breast_cancer.html)
- [UCI Machine Learning Repository: Wisconsin Diagnostic Breast Cancer](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic)

## Run the tutorial

Python 3.10 or newer is recommended.

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python src/analyze.py
```

The script is heavily commented and writes reproducible results to `outputs/`:

- `metrics.json` — test-set metrics and split counts;
- `predictions.csv` — test-set labels, scores, and predictions;
- `coefficients.csv` — standardized logistic-regression coefficients for discussion;
- `confusion_matrix.png` and `roc_curve.png` — plots generated by the tutorial.

Open `notebooks/breast_cancer_tutorial.ipynb` in Jupyter or upload it to Colab. The notebook explains each step and runs the same canonical script, avoiding a second, drifting implementation.

## Replication

The random seed, positive-class definition, split ratio, model, and metric calculations are explicit in `src/analyze.py`. Results can still vary across dependency versions and software platforms. See `REPLICATION_REPORT.md` for the actual rerun comparison and a student-facing checklist.

## Interpretation boundaries

- The target is a recorded benign/malignant label for samples in this benchmark, not a future clinical outcome.
- The features come from processed cell-nucleus measurements. They are not routine measurements from an electronic health record.
- A random split of one small dataset does not establish transportability, calibration, subgroup fairness, prospective utility, or patient benefit.
- The default 0.5 threshold is a teaching choice. Thresholds in medicine require a clinically justified trade-off and external validation.
- Model coefficients show associations used by this fitted model; they do not establish biological cause.
